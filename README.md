# 認知生態圈 (Cognitive Ecology) — 個人身心靈與生活管理 PWA

一款結合《Path of Exile》打寶掉落機制與《Melvor Idle》放置挖礦回饋的街頭賽博龐克風格個人身心靈管理 PWA。

## 四大核心模組
1. **雙軌算力雷達 (`EnergyRadar`)**：實體肉體 (HP) 與情緒算力 (MP) 0-100 滑桿監控；任一低於 30% 自動觸發紅框閃爍與「大爺模式」防禦提示。
2. **情緒過濾器 (`BoundaryFilter`)**：阿德勒課題分離實踐，「自我課題」納入精煉槽，「他人課題」觸發雷射劃除與粒子粉碎動畫。
3. **靈感掉落背包 (`InspirationLoot`)**：支援刺青手稿構想、饒舌歌詞、Podcast 題材，每次送出依 `Math.random()` 觸發 60% 白 / 25% 藍 / 10% 黃 / 5% 橘四色裝備卡掉落與混沌石重鑄。
4. **每日修復結算 (`DailyRecovery`)**：睡前「進入休眠」結算今日靈感數與情緒粉碎次數，生成專屬哲學語錄並將 HP/MP 回滿至 100%。
